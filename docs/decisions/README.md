# Design decisions

One file per decision, so we remember **why** we chose something over the alternatives. Brainstormed directions live in [`ideas/`](../../ideas/README.md). The decisions taken from them live here.

Name files `NNNN-short-title.md` (numbered in order, never renumbered). Sections:

- **Context:** the problem and the constraints.
- **Options:** each alternative in a line.
- **Decision and why:** why this one beat the others.
- **Consequences:** what it costs, what it unlocks, what we deferred.
